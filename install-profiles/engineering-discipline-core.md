# Engineering Discipline Core Install Profile

## Purpose

Use this profile to install core Lifecycle methodology with two
production-oriented Neutral organization discipline packages that are strongest
for general backend implementation work:

- test strategy
- Go engineering

These packages supply reusable discipline constraints, failure modes, proof
expectations, and bindings. Target product meaning must still be admitted
through semantic authority and Control records.
